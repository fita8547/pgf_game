# new-modeling — 추가·수정 에셋 (2026-11-11)

기존 `rps_assets/glb` 와 같은 규칙: 단위 m · Y-up · 캐릭터 정면 +Z · 총구 -Z.
같은 이름 파일(guns, fp_rigs, maps 3개)은 **기존 파일을 대체**하는 수정본입니다. 나머지는 전부 새 파일입니다.
`previews/` 에 확인용 렌더가 있습니다.

## 1순위

### ① 3인칭 공용 애니메이션 `glb/anims/third_person.glb`
클립 12개: `idle_gun, walk, run, strafe_L, strafe_R, back, crouch_idle, crouch_walk, jump, fire, reload, hit`

| 클립 | 길이 | 루프 |
|---|---|---|
| idle_gun | 2.4초 | O |
| walk / back | 1.0 / 1.1초 | O |
| run | 0.64초 | O |
| strafe_L / strafe_R | 0.9초 | O (L = 캐릭터 왼쪽 +X 로 이동) |
| crouch_idle / crouch_walk | 2.8 / 1.15초 | O |
| jump | 1.0초 | X (0.1 웅크림 → 0.2 도약 → 공중 → 0.82 착지) |
| fire | 0.25초 | X |
| reload | 1.85초 | X (1인칭 reload, 재장전 효과음과 같은 길이) |
| hit | 0.35초 | X |

- 노드에는 **뼈 빈 노드만** 있고 메시는 없습니다. 클립을 캐릭터 모델에 이름으로 바인딩해서 쓰면 됩니다.
- 회전 키: hips, spine, chest, neck, head, upper_arm_L/R, forearm_L/R, **hand_L/R**, thigh_L/R, shin_L/R, foot_L/R
  (총 방향을 맞추느라 손목(hand) 회전도 씁니다. 12명 모두 같은 이름이라 공용 그대로 동작)
- 위치 키: **hips 만**. 값 = 기준 골격(scroll) hips 레스트 `(0, 0.895, 0)` + 오프셋.
  다른 캐릭터에 쓸 때: `hips.position = 내_레스트 + (키값 − 0.895기준) × (내_레스트.y / 0.895)`
  (glb `asset.extras` 에도 같은 내용이 들어 있음. 그냥 쓰면 덩치 큰 캐릭터는 웅크릴 때 발이 살짝 뜸)
- 총은 `hand_R/weapon_socket_R` 에 붙은 상태 기준, 상체는 정면 조준 자세(왼어깨를 앞으로 돌린 자세).
- **fire / reload / hit 은 상체용**입니다. 하체도 서기 자세로 채워 둬서 단독 재생은 되지만, 걷기와 겹쳐 쓰려면
  이 세 클립에서 hips·thigh·shin·foot 트랙을 빼고(three.js: `clip.tracks.filter(...)`) 이동 클립 위에 올려 주세요.
- 엔진의 기존 3인칭 절차 자세 코드(`rps_engine.js` setPlayer 의 팔·다리 회전)는 이 클립으로 바꾸면 지우면 됩니다.
  조준 상하(pitch)는 지금처럼 chest/head 에 더해 주면 됩니다.

**알아 둘 점 — 왼손 위치**: 회전 키만 공용이라 어깨 너비 차이를 흡수할 수 없습니다. 12명 전체 오차가 최소가 되게 풀었고,
보통·마른 체형(scroll, pebble, origami, needle, snip, staple 등)은 왼손이 총 앞을 정확히 받칩니다.
덩치 큰 **볼더·카드보드**는 왼손이 총 옆으로 15~20 cm 벌어집니다. 딱 맞추려면 엔진에서 왼팔만 2관절 IK로
`weapon_socket_R` 기준 총 로컬 `(0, -0.05, -0.20)` 지점에 붙이면 됩니다.
왼손 받침점은 소총·SMG·샷건 손잡이 앞 기준이라, 권총류는 왼손이 총구보다 조금 앞에 있습니다.

### ② 총구 노드 `muzzle`
- `glb/guns/*.glb` 7개: 루트 바로 아래 `muzzle` (총 로컬 좌표)
- `glb/fp_rigs/*.glb` 7개: `weapon` 아래 `muzzle` → 반동·재장전 애니메이션을 그대로 따라감
- 위치: 각 총의 가장 앞 파츠 끝에서 5 mm 앞. 런처는 장전된 탄두 끝.
- 그 외 노드·메시·애니메이션은 기존 파일과 완전히 같습니다(스크립트 재생성 결과가 기존 glb 와 바이트 단위로 일치하는 것을 확인 후 노드만 추가).

### ③ 맵 수정 (충돌은 맵 glb 에서 자동 생성되므로 glb 교체만 하면 게임 판정도 같이 바뀜)
- **neon_rooftops**
  - 다리가 닿는 옥상 가장자리 난간 20곳에 입구를 뚫음 (다리 폭 3 m + 여유, 대각선 다리는 비스듬한 만큼 넓게)
  - `barrier_n1` / `barrier_n-1`: 4·5번 다리 위(0, ±20)에서 중앙 옥상의 다리 머리 옆 (±4.5, ±5.2)으로 옮김
  - `bridge_6/7` 이 `bridge_4/5` 를 관통하던 문제: 4·5번 다리 위에서 만나는 T자 연결로 바꿈
    (`bridge_6` + `bridge_6b`, `bridge_7` + `bridge_7b`, 4·5번 다리 난간은 만나는 곳만 끊김)
  - **추가로 발견해서 같이 고친 것**
    - 다리 회전 순서 버그: 원래 `r=(경사, 방향, 0)` 이라 x방향 다리(0·1·6·7번)가 경사 대신 옆으로 기울어 있었고,
      2번은 경사가 반대였음 → 경사 후 방향 순으로 고침. 경사 다리 길이도 평면 길이 → 경사 길이로 바꿔 양 끝이 옥상에 정확히 닿음
    - 2·3번 다리가 위쪽 끝이 1·2번 건물 밖 허공(x=±12)에 떨어져 있어서 x=±15로 옮김
- **rps_arena**: 창고 계단(`wh_stair_0~6`)이 메자닌 반대쪽으로 올라가던 것을 메자닌 끝(x=-24, 높이 2.5 m)으로 올라가게 바꿈.
  계단 입구를 막던 드럼통 w1·w2 를 동쪽 벽 쪽으로 옮기고, 계단 옆판 추가
- **frost_harbor**: 바닥(`ground`)을 바다 경계 x=19 까지만 남김. 잘린 단면 아래에 부두 벽(`quay_wall`) 추가.
  바다에 빠지면 해저(y -0.7)에 서고, 점프로 올라올 수 있음

기존 `rps_assets/src` 전체 + 수정·추가분. 기존 `build.py` 도 그대로 동작합니다(총에 muzzle 포함).
- `python3 src/build_new.py` → new-modeling 의 glb 전부 재생성 (3인칭 IK 계산 때문에 수 분 걸림)
- 수정한 파일: `guns_hq.py`(MUZZLE), `fp.py`(리그에 muzzle), `map_arena.py`, `maps_more.py`, `meshlib.py`(파츠 `mn` 키로 머티리얼 이름 지정, 없으면 기존과 동일), `build.py`

- `sfx_new.py` 는 `song/rps_sfx/` 에 복사해서 `python3 sfx_new.py` (sfx.py·music.py 사용)
